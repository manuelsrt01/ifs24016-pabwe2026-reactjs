# Lost & Found — ReactJS (ifs24016-pabwe-p4-reactjs)

Stack: React 19, Vite, Tailwind CSS v4, Redux Toolkit, React Router, SweetAlert2, Vitest + Testing Library.

## Menjalankan

```bash
bun install        # atau: npm install
bun run dev        # http://localhost:3000
bun run test
bun run test:coverage
```

Konfigurasi API ada di `.env` (`VITE_API_BASE_URL`).
